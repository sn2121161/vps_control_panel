# 部署验证记录

日期：2026-11-09。本文件不包含真实服务器地址、凭据或订阅链接。

## 已验证

- 使用官方固定版本 3x-ui 3.11.0，固定镜像 digest；配套 Xray 26.10.21。
- 公网 HTTPS 使用受信任 IP 证书；未认证状态页返回 401；管理员和状态页登录分别通过。
- 面板与订阅后端、Xray 管理与指标接口只监听回环地址；外部只开放规划服务端口。
- 两台设备独立订阅只包含各自的代理凭据；生成的订阅有国内直连规则和独立 DNS 策略。
- 使用 Mac 已有 Mihomo v1.19.33 的独立进程校验配置并测试，不改动原客户端订阅或系统代理。
- 海外请求通过 VPS 出口，YouTube 连接测试成功；国内请求命中国内直连规则并成功。
- 受控停止代理时国内请求仍成功、海外请求失败；恢复后可重新连接。
- Xray 配置校验通过，最终 REALITY 目标不再产生原目标的配置警告。
- 证书 staging 签发、正式签发和 dry-run 续期成功，deploy hook 执行 Nginx 配置检查及 reload。
- 状态页正常展示；模拟续期故障能够弹窗，模拟数据已清除。页面关闭和服务器故障时不承诺离线提醒。
- 普通初始压缩备份生成；SQLite 完整性检查通过；隔离无网络容器能够从归档数据库启动面板。
- 备份目录权限 700、归档权限 600；备份含敏感配置，仅服务器保存，用户自行下载。
- 两个合成数据测试通过：备份可恢复/白名单排除无关密钥/重复运行不覆写；遇到符号链接拒绝并清理维护标志。
- 月度备份定时器按 Asia/Shanghai 时区设定，另有失败重试、证书检查、健康采集任务。

## 尚需实机与持续验收

- 小米客户端导入及手机流量下的实际连接、分流与退出恢复。
- 晚高峰两台各三小时 1080p；五台高峰一小时，允许部分降低画质。
- Netflix 使用实际账号播放，X 和 Spotify 实际使用；连接请求成功不等于平台解锁或会员播放通过。
- 后续真实到期前续期、真实月初任务和长期运行情况。短期部署测试不能证明长期稳定或永不被封。

测试结果不代替上述验收，不把端口正常、HTTP 成功或合成测试称为完整视频体验通过。
